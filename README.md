# DevTrack

DevTrack is a web application designed to help university students organize
their academic work and self-learning activities in one place.

## Problem

Students who combine university study with independent learning often keep
tasks, projects, deadlines, and progress across different tools.

This makes it difficult to understand:

- What has been completed
- What is currently in progress
- What is still pending
- What has been placed on hold
- What should be done next

## MVP

The first version will include:

- User registration
- Login and logout
- Password reset by email
- Projects and learning areas
- Task management
- Task statuses
- Priorities
- Planned start dates
- Due dates
- Estimated duration
- Progress tracking
- Responsive dashboard

## Planned Technology Stack

- Python
- Django
- PostgreSQL
- Bootstrap
- Vanilla JavaScript
- Git and GitHub
- Docker
